Overview

What it does

Shape EQ holds two complete EQ curves, A and B, across six bands from a low shelf to a high shelf. Set each band’s gain for A and for B, then morph between the two shapes.

Drive the morph by hand, with an LFO, or from the input level, so the tone can sweep in time or open up as you play harder. The display shows both curves over the output spectrum, so you can see where the morph is taking you.

Features

Key features

  • Dual-curve morph EQ: six bands, each with its own A and B gain
  • Morph by hand, LFO or input level
  • Display shows both curves over the output spectrum
  • Folix neon interface
